硅基流动免费额度怎么领：16 元通用代金券与长期免费模型

硅基流动（SiliconFlow）是目前国内少数同时提供注册赠金和长期免费模型的平台。这篇说清楚两件事：代金券怎么拿、免费模型有哪些，以及用之前要知道的限制。

一句话结论：完成注册和实名认证，可以拿到 16 元全平台通用代金券，180 天有效；另外有若干款模型本身长期标价 0 元，不消耗代金券。活动截止 2026-12-31。

代金券的规则

  • 触发条件：被邀请人完成注册并完成首次实名认证，代金券在 1～5 分钟内自动到账。
  • 面值与有效期：¥16，自发放之日起 180 天有效，逾期自动失效。
  • 适用范围：全站通用，可抵扣 API 调用、批量推理、微调训练。具体可用商品以领取当日平台展示为准。
  • 使用顺序：结算时优先消耗代金券（按到期时间先到先用），代金券用尽后才扣账户充值余额。
  • 查看路径：登录后进【账户管理】→【余额充值】→【我的代金券】。

注意代金券是平台抵扣券，不能提现、不能转让，只能用于自己消耗模型调用。

领取步骤

  1. 通过领取入口注册账号（手机号即可）。
  2. 进入【账户管理】→【实名认证】，完成个人实名。国内平台的赠送活动基本都要过这一关。
  3. 认证通过后，代金券自动到账，去【余额充值】→【我的代金券】确认。
  4. 创建 API 密钥，接口地址填 https://api.siliconflow.cn/v1，格式兼容 OpenAI SDK，国内可直连。

几个容易踩的坑

  • 非 Pro 模型不等于免费。免费的是上面那几款标注 0 元的模型，不是全部非 Pro 模型，接之前核对价格页。
  • 重复认证不发奖励。同一个身份信息二次认证、解绑后重新绑定，都不会触发新的代金券。
  • 限速是存在的。免费模型有 RPM 限制（大致 1000–10000 区间，按模型不同），高并发场景要排队或降级。
  • 代金券有截止日。活动 2026-12-31 结束，之后是否续期以官方公告为准。

常见问题

赠金和充值余额，先用哪个？

先用代金券。平台按到期时间从近到远扣减，代金券用尽后才动充值余额，所以不用担心充值之后赠金被"放着过期"。

一定要实名吗？

要。国内的赠送类活动受监管要求，未完成实名认证的账号拿不到奖励，部分模型能力也会受限。

免费模型会不会突然收费？

会调整。这类"长期免费"本质上属于平台补贴，历史上多个平台的免费层都在没有预告的情况下收缩过。建议在代码里把模型名做成配置项，随时能切。
